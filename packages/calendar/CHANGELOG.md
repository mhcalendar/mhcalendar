# Changelog

## [0.1.2] - 2026-04-23

### Added
- **Shiftplan view** — New calendar view designed for shift-based scheduling with multi-event display per slot.
- **Timezone support** — Full support for multiple IANA timezones simultaneously, including correct event rendering and navigation across zones.
- **Config validator** — Runtime validation of the calendar configuration with descriptive error messages.
- **Event hover effect** — Brightness change on event hover for improved visual feedback.
- **Event resizing animation** — Smooth animation when resizing events via drag handle.

### Fixed

- Agenda view rendering and default navigation.
- Modal validation for event editing.
- Current time indicator position.
- Performance improvements for calendars with many events.
- Event display when a custom timezone is set.
- Drag & drop between all-day and timed slots.
- Business hours drag boundary enforcement.
