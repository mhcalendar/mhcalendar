# Installation

:::warning Pre-1.0 package
mhcalendar is still `0.x.x`. Minor and patch releases can contain breaking changes. Pin an
**exact** version rather than a caret range in production, and check the
[Changelog](/docs/changelog) before bumping.
:::

## React

```bash
npm install @mhcalendar/react
```

`@mhcalendar/react` depends on `@mhcalendar/calendar` directly, so it's installed automatically —
there's no separate custom-element registration step. Peer dependencies are `react` and
`react-dom` (`>=18.0.0`, also compatible with React 19).

## Vanilla JS / any other framework

```bash
npm install @mhcalendar/calendar
```

`@mhcalendar/calendar` only depends on `dayjs`. Because it's a plain Web Component, it also works
directly from a `<script type="module">` tag without a bundler — see
[Quick Start](/docs/overview/quick-start) for both patterns.

## Requirements

- Node.js is only needed for the build tooling — the shipped component runs in any modern
  evergreen browser (Chrome, Firefox, Safari, Edge) with native Custom Elements support.
- React usage requires React 18 or 19.
