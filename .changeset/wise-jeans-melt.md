This release adds a native Stencil modal, a new event-list popover (day/week and resource views), agenda view improvements, extra config labels, and a vanilla JS example. It also fixes resize handling and drag/drop preview in the resource view, event rendering in month/resource views, the event grouping algorithm, and improves performance for large numbers of events. Alongside these, the repo gained community health files (LICENSE, CODE_OF_CONDUCT, issue templates) and README updates.
