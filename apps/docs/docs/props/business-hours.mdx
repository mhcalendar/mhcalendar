# `businessHours` / `blockBusinessHours`

| Prop | Type | Default | Description |
|---|---|---|---|
| `businessHours` | `{ dayOfWeek?, date?, start, end }[]` | `[]` | One or more availability windows; matched by specific `date` > `dayOfWeek` > a default entry with neither. |
| `blockBusinessHours` | `boolean` | `false` | Prevents dropping/resizing events outside business hours. |

```tsx
const config = {
  businessHours: [{ dayOfWeek: [1, 2, 3, 4, 5], start: 9, end: 17 }],
  blockBusinessHours: true,
};
```

By default, the non-business-hours overlay is purely visual — `blockBusinessHours: true` is what
actually prevents dragging/resizing an event into that range (see
[Dragging & resizing](/docs/props/event-drag-resize)). Full priority rules for overlapping
`date`/`dayOfWeek` entries, and styling the overlay color, are covered in
[Business hours](/docs/guides/business-hours).
