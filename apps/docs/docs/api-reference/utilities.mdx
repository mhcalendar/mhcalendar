# Utilities

Neither `@mhcalendar/calendar` nor `@mhcalendar/react` currently exports standalone utility
functions. Date math, timezone conversion, and business-hours calculation are implemented
internally (e.g. `TimezoneUtils`, `DateUtils`, `BusinessHoursUtils`) but are private
implementation details, not part of the public API — they aren't exported from either package's
entry point and aren't covered by semver guarantees.

`dayjs` is a regular (non-peer) dependency of `@mhcalendar/calendar`, bundled for internal use —
it isn't re-exported for you to import from the calendar packages. If you need date utilities in
your own app code, add `dayjs` (or your date library of choice) as your own dependency directly.

If you find yourself needing a specific exported helper (e.g. the timezone formatting used
internally), that's worth a feature request — check the [Changelog](/docs/changelog) for whether
it's already been added in a newer release.
