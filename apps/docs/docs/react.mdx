# React Integration

Use `@mhcalendar/react` to consume the Stencil component in React projects.

## Install

```bash
npm i @mhcalendar/react
```

## Basic usage

```tsx
import { MhCalendar } from '@mhcalendar/react';

export function CalendarView() {
  return <MhCalendar config={{ viewType: 'WEEK' }} events={[]} />;
}
```

## Recommendation

Keep events in React state and treat calendar callbacks as external state updates.
