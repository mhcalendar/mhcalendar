# Theming

There's no built-in theme registry or provider — a "theme" in mhalendar is just a plain object
you build once and reuse, following the same `config.style` shape from [Styling](/docs/guides/styling).
This guide shows the pattern this documentation site itself uses for its live demos.

## Defining a theme object

```ts
// themes/corporate.ts
export const corporateTheme = {
  properties: {
    eventBackgroundColor: '#1e3a8a',
    bordersColor: '#cbd5e1',
    headerTodayBackgroundColor: '#fff1f2',
    currentTimeColor: '#e11d48',
    eventTimeLabelBg: '#172554',
    eventTimeLabelColor: '#bfdbfe',
  },
  mhCalendar: { backgroundColor: '#ffffff', color: '#1e293b' },
};
```

```tsx
import { corporateTheme } from './themes/corporate';

<MhCalendar config={{ viewType: 'WEEK', style: corporateTheme }} events={events} />;
```

Because it's just data, you can keep a small set of named themes and switch between them at
runtime — e.g. a light/dark toggle, or a per-tenant brand theme in a multi-tenant product:

```tsx
const THEMES = { corporate: corporateTheme, dark: darkTheme, minimal: minimalTheme };

function App() {
  const [themeName, setThemeName] = useState<keyof typeof THEMES>('corporate');
  const config = useMemo(() => ({ viewType: 'WEEK', style: THEMES[themeName] }), [themeName]);
  return <MhCalendar config={config} events={events} />;
}
```

## Combining with `config.theme`

`config.theme: 'light' | 'dark'` picks the base defaults your theme object's overrides are layered
on top of — pick whichever base is closer to your target look before overriding individual
properties, so you override fewer of them.

## Tying it to your app's own theme (light/dark mode)

The calendar's `theme`/`style` are independent from any app-level theme switcher (e.g. a
`data-theme` attribute on `<html>`) you may already have for the rest of your UI. If you support
light/dark mode, drive the calendar's `style` from the same state instead of two separate toggles:

```tsx
const config = useMemo(
  () => ({
    viewType: 'WEEK',
    theme: appTheme,
    style: appTheme === 'dark' ? darkTheme : corporateTheme,
  }),
  [appTheme],
);
```
