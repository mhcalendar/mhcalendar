# Events

Events are passed as an array to the `events` prop.

## Event shape

```ts
type IMHCalendarEvent = {
  id: string;
  title: string;
  startDate: Date;
  endDate: Date;
  allDay?: boolean;
  color?: string;
};
```

## Notes

- Events are grouped internally by date key.
- Multi-day events are duplicated across all date keys they span.
- Drag/resize updates can be observed through callback handlers in config.
