# `style`

| Prop | Type | Default | Description |
|---|---|---|---|
| `style` | `{ properties?, [className]: CSSinJS }` | `{}` | CSS custom properties (`properties`) plus per-class inline overrides keyed by class name, as siblings on the same object. |

```tsx
const config = {
  style: {
    properties: { eventBackgroundColor: '#1e3a8a', bordersColor: '#cbd5e1' },
    mhCalendar: { fontFamily: "'Courier New', monospace" },
  },
};
```

Every component renders with `shadow: false` — there's no Shadow DOM boundary and no `::part()`
selectors to learn, so `style` (custom properties + per-class overrides) is the only styling
surface. This is big enough to warrant its own guide — see [Styling](/docs/styling) for the
full custom-property table and class list, and [Theming](/docs/guides/theming) for reusing a style
object as a named theme.
