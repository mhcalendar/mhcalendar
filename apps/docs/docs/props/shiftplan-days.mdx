# `shiftplanDays`

| Prop | Type | Default | Description |
|---|---|---|---|
| `shiftplanDays` | `number` | `7` | Number of days shown in the Shiftplan view. |

```tsx
const config = { viewType: 'SHIFTPLAN', shiftplanDays: 14 };
```

## Reserved, not implemented yet

Two more fields exist on the type today but don't do anything yet — reserved for a future release:

| Prop | Type | Default |
