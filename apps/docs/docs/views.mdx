# Views

MH Calendar supports five main views:

- `DAY`
- `WEEK`
- `MONTH`
- `AGENDA`
- `SHIFTPLAN`

Switching view can be done through:

- config (`viewType`)
- navigation UI
- user API methods

Each view shares the same event source but has different rendering and interaction behavior.
