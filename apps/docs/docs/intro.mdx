# MH Calendar Documentation

This docs app lives in the monorepo at `apps/docs` and documents:

- `@mhcalendar/calendar` (Stencil core package)
- `@mhcalendar/react` (React wrapper package)

## Local development

From repository root:

```bash
npm run docs
```

Build static files:

```bash
npm run docs:build
```

## Project links

- GitHub: [mhcalendar/mhcalendar](https://github.com/mhcalendar/mhcalendar)
- Core package: `packages/calendar`
- React wrapper: `packages/react`
