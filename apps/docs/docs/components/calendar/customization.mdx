# Customization

mhalendar can be customized on two independent axes: **how it looks** (CSS) and **how event
content renders** (render functions). Both are driven from `config` — there's no theming context
or CSS-in-JS provider to wire up.

## Visual styling

Because every component renders with `shadow: false` (no Shadow DOM), there are no `::part()`
selectors to learn — styling is plain CSS custom properties and class selectors, scoped by a
`mh-calendar, mh-calendar *` reset. Two levers, both under `config.style`:

- `style.properties` — CSS custom properties (colors, fonts, sizes) applied as inline styles on
  the host element, e.g. `--eventBackgroundColor`, `--bordersColor`.
- `style.styles` — per-class inline style overrides for finer-grained control, e.g. the header row
  or a specific event class.

Plus `config.theme: 'dark' | 'light'` to start from one of the two built-in presets before
layering your own overrides on top.

This is big enough to warrant its own guide — see [Styling](/docs/guides/styling) for the full
property reference and [Theming](/docs/guides/theming) for building a reusable named theme.

## Custom event rendering

Two `config` functions let you replace the default event markup entirely:

| Prop                | Used in                                    |
| ------------------- | ------------------------------------------ |
| `eventContent`      | Full-size events (Day/Week views).         |
| `eventSmallContent` | Compact events (Month, Shiftplan, Agenda). |

Both receive the `IMHCalendarEvent` object and return renderable content:

```tsx
const config = {
  eventContent: (event) => (
    <div className="my-event">
      <strong>{event.title}</strong>
      {event.description && <p>{event.description}</p>}
    </div>
  ),
  eventSmallContent: (event) => <span>{event.title}</span>,
};
```

If you only need to change colors per event rather than the whole markup, it's usually simpler to
set `event.color` on individual events instead of overriding rendering — see
[Events](/docs/components/calendar/events#the-event-shape--imhcalendarevent).
